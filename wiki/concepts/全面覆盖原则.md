# 全面覆盖原则

## 概述

全面覆盖原则（All Elements Rule）是专利侵权判断的最基本原则。指在被诉侵权技术方案中，包含了权利要求中记载的**全部技术特征**，则认定其落入专利权的保护范围。

这是侵权分析的**第一步**，也是最基础的判断。

## 判断标准

如果被诉侵权技术方案包含与权利要求记载的**全部技术特征相同**或者**等同**的技术特征，则认定落入保护范围。

### 三种覆盖情形

| 情形 | 判定结果 | 说明 |
|------|---------|------|
| 全部相同 | ✅ 侵权 | 被诉方案包含权利要求中每个特征的相同表述 |
| 部分等同 | ✅ 侵权 | 被诉方案以等同手段替代了部分特征 |
| 缺少特征 | ❌ 不侵权 | 被诉方案缺少权利要求中的一个或多个特征 |
| 额外特征 | ✅ 侵权 | 被诉方案包含全部特征 + 额外特征，仍构成侵权 |

## 实务应用

### 产品审查中的应用

在制作 [[wiki/concepts/专利权利要求对照表|权利要求对照表]] 时，逐项比对：

1. 解析权利要求中的每一个技术特征（Element）
2. 逐一比对产品是否包含该特征
3. 如全部要素均覆盖 → 进入 [[wiki/concepts/等同原则|等同原则]] 进一步分析
4. 如有要素缺失 → 初步判定不侵权（仍需考虑等同原则是否适用）

### 避让设计（Design Around）策略

若产品缺一个必要特征即可避开全面覆盖：
- 删除该特征
- 用实质性不同的方式实现该功能
- 注意避免落入等同原则的范畴
