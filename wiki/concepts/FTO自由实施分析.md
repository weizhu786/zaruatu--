# FTO 自由实施分析

## 概述

FTO（Freedom to Operate，自由实施分析）是在产品上市前，对其在目标市场是否侵犯他人有效专利权进行的系统性调查和分析。FTO 是专利侵权审核的核心流程。

## FTO 分析流程

```
产品信息收集 → 专利检索 → 筛选相关专利 → 权利要求对照 → 风险评估 → 出具报告
```

### 第一步：产品信息收集
- 产品的技术方案、结构、功能、外观
- 目标市场（美国、中国、欧盟等）
- 产品上架平台（Amazon、eBay、独立站等）

### 第二步：专利检索
按 [[wiki/concepts/外观专利检索|外观专利检索]] 指南在以下数据库查询：

| 市场 | 必查数据库 |
|------|-----------|
| 美国 | USPTO PPUBS |
| 中国 | CNIPA 外观设计检索系统 |
| 欧盟 | EUIPO DesignSearch |
| 全球 | WIPO Global Design Database |
| 综合 | 智慧芽 PatSnap（以图搜图） |

### 第三步：权利要求对照
制作 [[wiki/concepts/专利权利要求对照表|权利要求对照表]]，使用 [[wiki/concepts/全面覆盖原则|全面覆盖原则]] 和 [[wiki/concepts/等同原则|等同原则]] 逐项分析。

### 第四步：风险评估
| 风险等级 | 定义 | 建议行动 |
|---------|------|---------|
| 低 | 未发现相关有效专利 | 可正常上架 |
| 中 | 存在外观相似专利但可论证不侵权 | 建议法律意见后上架 |
| 高 | 产品落入有效专利保护范围 | 修改设计或获取许可 |
| 极高 | 高风险专利 + TRO 可能性大 | 不建议上架 |

## FTO 频率建议

| 阶段 | 频率 | 说明 |
|------|------|------|
| 选品阶段 | 每次选品 | 初步快速检索过滤 |
| 开发/修改后 | 每次改版 | 确认修改未产生新风险 |
| 上架前 | 最终 FTO | 全面排查，留档备查 |
| 定期监控 | 每月 | 监控新授权专利 |
