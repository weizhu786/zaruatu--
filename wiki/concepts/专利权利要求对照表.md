# 专利权利要求对照表（Claim Chart）

## 概述

权利要求对照表（Claim Chart）是专利侵权分析的标准输出格式。它将专利权利要求中的每个技术特征与被诉产品的对应特征逐项列出比对，是侵权判定和法庭证据的核心文件。

## 标准格式

### 表格结构

| 权利要求要素 | 被诉产品特征 | 是否覆盖 | 备注 |
|-------------|-------------|---------|------|
| 权利要求中的原文表述 | 产品对应特征描述 | ✅/❌/⚠️ | 等同分析 |
| 要素 2 原文 | 产品对应特征 | ✅/❌/⚠️ | |
| 要素 3 原文 | 产品对应特征 | ✅/❌/⚠️ | |

### 符号说明
| 符号 | 含义 |
|------|------|
| ✅ | 字面覆盖（Literal Infringement） |
| ⚠️ | 等同覆盖（Equivalent） |
| ❌ | 未覆盖（Non-infringement） |
| ❓ | 待确认 |

## 制作步骤

1. **解析权利要求** — 将权利要求拆分为独立的技术特征（Elements）
2. **确定产品特征** — 明确被诉产品的对应技术特征
3. **逐项比对** — 按 [[wiki/concepts/全面覆盖原则|全面覆盖原则]] 判断字面覆盖
4. **等同分析** — 对未字面覆盖的特征按 [[wiki/concepts/等同原则|等同原则]] 分析
5. **汇总结论** — 所有特征被覆盖 → 可能侵权；有特征缺失 → 初步不侵权

## 使用场景

| 场景 | 用途 |
|------|------|
| 产品 FTO 分析 | 评估新品是否侵犯现有专利 |
| 侵权警告应对 | 分析对方专利是否有效、产品是否侵权 |
| 诉讼准备 | 作为法庭证据的标准化格式 |
| 避让设计 | 精确定位需要修改的特征 |
