# 产品审查看板

> 实时展示所有产品的审查状态 — 数据自动从产品页 frontmatter 更新

---

## 📊 总览

```dataview
TABLE 
  length(rows) as "数量"
FROM "wiki/products"
WHERE type = "product-review"
GROUP BY status
SORT status ASC
```

```dataview
TABLE 
  length(rows) as "数量"
FROM "wiki/products"
WHERE type = "product-review"
GROUP BY risk_level
SORT risk_level ASC
```

---

## ⏳ 待审核（Pending）

```dataview
TABLE 
  product as "产品",
  risk_level as "风险",
  target_markets as "市场",
  created as "建档日期"
FROM "wiki/products"
WHERE type = "product-review" AND status = "pending"
SORT created ASC
```

---

## 🔍 审查中（In Review）

```dataview
TABLE 
  product as "产品",
  reviewer as "审核人",
  risk_level as "风险",
  target_markets as "市场",
  updated as "最近更新"
FROM "wiki/products"
WHERE type = "product-review" AND status = "in-review"
SORT updated DESC
```

---

## ✅ 已通过（Cleared）

```dataview
TABLE 
  product as "产品",
  risk_level as "风险等级",
  target_markets as "市场",
  updated as "审核完成"
FROM "wiki/products"
WHERE type = "product-review" AND status = "cleared"
SORT updated DESC
```

---

## ⚠️ 高风险 / 已拦截（Risky / Blocked）

```dataview
TABLE 
  product as "产品",
  risk_level as "风险等级",
  patents_found as "相关专利",
  target_markets as "市场"
FROM "wiki/products"
WHERE type = "product-review" AND (status = "risky" OR status = "blocked")
SORT risk_level ASC
```

---

## 👥 按开发员分组

```dataview
TABLE 
  rows.product as "产品",
  rows.status as "状态",
  rows.risk_level as "风险"
FROM "wiki/products"
WHERE type = "product-review" AND reviewer
GROUP BY reviewer as "开发员"
SORT reviewer ASC
```

---

## 🌍 按目标市场分组

```dataview
TABLE 
  rows.product as "产品",
  rows.status as "状态",
  rows.risk_level as "风险"
FROM "wiki/products"
WHERE type = "product-review"
FLATTEN target_markets
GROUP BY target_markets as "市场"
SORT target_markets ASC
```

---

## 📋 全部产品一览

TABLE
