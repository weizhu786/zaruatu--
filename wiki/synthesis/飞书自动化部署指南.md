# 🚀 飞书专利审核自动化 — 部署指南

> **目标**：同事在飞书填表单 → AI 自动审查 → 飞书机器人推送报告，全程无需人工中转。

---

## 一、架构总览

```
┌──────────┐     提交表单     ┌──────────┐    Webhook    ┌────────────┐   AI审查   ┌──────────┐
│ 同事飞书  │ ──────────────→ │ 飞书服务端 │ ────────────→ │ 后端服务器  │ ────────→ │ Claude   │
│  表单     │                 │   Bot    │              │  (FastAPI) │           │  API     │
└──────────┘                 └──────────┘              └────────────┘           └──────────┘
                                   ↑                         │
                                   │    推送审查报告           │
                                   └─────────────────────────┘
```

---

## 二、部署步骤（需逐步完成）

### ⚠️ 前置条件

| 条件 | 说明 |
|:----|:-----|
| 🔑 Claude API Key | [console.anthropic.com](https://console.anthropic.com) → API Keys |
| 💳 充值 | 推荐充 $20，约可审查 100-200 个产品 |
| 🏢 飞书管理员权限 | 创建应用、配置机器人 |
| ☁️ 服务器 | Railway / 阿里云 / 腾讯云 / 你的电脑 |

---

### ▶️ 步骤 1：飞书创建应用

1. 打开 [飞书开放平台](https://open.feishu.cn)
2. 点击「创建企业自建应用」
3. 名称：**专利审核助手**
4. 图标：上传任意图标

#### 添加能力

进入应用 →「添加应用能力」→ 勾选：
- ✅ **机器人**（用于推送消息）
- ✅ **网页应用**（用于表单提交回调）

#### 配置权限

进入「权限管理」→ 添加以下权限：
- `im:message:send_as_bot` — 发送消息
- `im:message:read` — 读取消息
- `contact:user.id:readonly` — 获取用户 ID

#### 获取凭证

进入「凭证与基础信息」→ 记录以下三个值：
```
APP_ID        = cli_xxxxxxxxxxxx
APP_SECRET    = xxxxxxxxxx
VERIFICATION_TOKEN = xxxxxxxxxx
```

---

### ▶️ 步骤 2：创建飞书表单

在飞书工作台：

1. 新建 →「多维表格」→ 命名为「产品专利审核提交」
2. 创建以下字段：

| 字段名 | 类型 | 必填 | 说明 |
|:------|:----:|:----:|:-----|
| 产品编号 | 文本 | ✅ | 如 999 |
| 产品名称 | 文本 | ✅ | 如 硅胶杯盖 |
| 产品标题 | 多行文本 | ✅ | 完整 Amazon Listing 标题 |
| 目标市场 | 单选 | ✅ | US / CA / EU / FR / JP |
| 材质 | 文本 | | 如 不锈钢、硅胶 |
| 品牌名 | 文本 | | |
| 五点描述 | 多行文本 | | Amazon Bullet Points |
| 产品图片 | 附件 | | 多角度产品照片 |
| 开发员 | 文本 | | |
| 参考链接 | 链接 | | Amazon ASIN |

3. 表单设置 →「表单提交时」→ 添加「Webhook」动作
4. Webhook URL 填入：`https://你的服务器地址/feishu/webhook`

---

### ▶️ 步骤 3：部署服务器

#### 方案 A：Railway（推荐，最简单）

1. 打开 [railway.app](https://railway.app) 用 GitHub 登录
2. New Project → Deploy from GitHub Repo → 选 `zaruaatu--` 仓库
3. 设置 Root Directory 为 `server`
4. 添加环境变量（Variables）：

```
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxx
FEISHU_APP_ID=cli_xxxxxxxxxxxx
FEISHU_APP_SECRET=xxxxxxxxxx
FEISHU_VERIFICATION_TOKEN=xxxxxxxxxx
PORT=8000
```

5. 部署 → 获得域名如 `xxx.up.railway.app`
6. 把 Webhook URL 更新为 `https://xxx.up.railway.app/feishu/webhook`

#### 方案 B：阿里云 / 腾讯云轻量服务器

```bash
# SSH 登录服务器后
git clone https://github.com/weizhu786/zaruaatu--.git
cd zaruaatu--/server

# 安装依赖
pip install -r requirements.txt

# 创建 .env 文件，填入配置
nano .env

# 运行
python main.py
# 或后台运行
nohup python main.py > app.log 2>&1 &
```

#### 方案 C：在自己电脑上运行

```bash
cd E:\审核\审核\server
pip install -r requirements.txt
copy .env.example .env
# 编辑 .env 填入真实的 API Key
python main.py
```

> ⚠️ 需要保持电脑 24 小时开机，适合测试阶段。

---

### ▶️ 步骤 4：上线飞书应用

1. 飞书开放平台 → 你的应用 →「应用发布」
2. 选择可见范围 →「所有成员」
3. 提交审核 → 发布

```
1. 同事打开飞书 → 工作台 →「产品专利审核提交」表单

4. 专利审核助手机器人发消息："⏳ 正在审查中…"
5. 3-8 分钟后收到审查报告：
```
