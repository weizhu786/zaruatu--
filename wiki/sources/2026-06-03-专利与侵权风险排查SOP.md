# 专利与侵权风险排查SOP

> **来源**：外置大脑知识库 · 选品合规检查流程
> **原文**：[[raw/2026-06-03-专利与侵权风险排查SOP]]

> **⚠️ 管辖权优先级已更新 2026-06-05**：新增「管辖权匹配」核心原则——目标市场是哪些国家就只查这些国家的数据库，非目标市场 IP 不查不写（详见 CLAUDE.md 管辖权优先级规则）

## 概述

本文档建立了一个系统化的侵权风险排查流程，覆盖商标、设计专利、发明专利、版权四个维度，采用 **五层递进排查漏斗** 结构：

```
第一层：产品特征拆解（含印刷图案触发判断）
➡ ⚠️ 版权排查层（印刷图案/文字触发时执行）
➡ 第二层：商标排查
➡ 第三层：设计专利排查
➡ 第四层：发明专利排查（功能性产品跳过）
➡ 第五层：供应商与市场验证
➡ 最终判断：Go / No-Go / 需修改设计
```

## ⚠️ 核心原则：管辖权匹配

> **847 教训**：知识产权的保护是地域性的。美国专利只在美国有效，加拿大专利只在加拿大有效。
> 
> **核心逻辑**：目标市场是哪些国家，就只查这些国家的数据库。一个都不少，一个都不多。非目标市场的 IP 对决策没有参考价值。

目标市场 → 数据库映射详见 [[CLAUDE.md#管辖权优先级规则]]

## 关键要点

| 层级 | 核心工具（匹配 `target_markets`） | 输出 |
|:----:|----------------------------------|------|
| 第一层 | 产品信息 + 图片/PIL 分析 | 产品特征清单 + **目标市场逐个映射为数据库列表** |
| 第二层 | **各目标市场的商标局**（US→USPTO TESS, CA→CIPO, EU→EUIPO）+ Listing 扫描 | 每个目标市场的独立商标风险结论 |
| 第三层 | **各目标市场的设计专利库**（US→USPTO PPUBS, CA→CIPO, EU→EUIPO）/ WIPO（仅筛选目标国） | 每个目标市场的设计专利列表 |
| 第四层 | **各目标市场的专利局**（US→USPTO, CA→CIPO, EU→EPO）/ Google Patents（按目标国过滤） | 每个目标市场的 Claim Chart + 判定 |
| 第五层 | AliExpress / Etsy / eBay / Justia / PACER | 市场验证结论 |
| 最终 | 综合矩阵（**按目标市场分别评估**） | 每个市场的独立结论 |
