# 专利与侵权风险排查SOP——AI可参考的选品合规检查流程

> **本文目的**：建立一个系统化的侵权风险排查流程，覆盖商标、设计专利、发明专利、版权四个维度。可被AI按步骤执行，也可被选品团队按流程操作。
>
> **思考路径**（写在前面）：现有知识库里，[[市场分析法]] 只在供应商分析中提到"如为定制产品，要求专利号并自行验证"，[[Amazon选品方法论总览]] 在避坑指南中有一条"FBM表现好但不持久→可能侵权"。这两条的覆盖范围远远不够——Owala的案例里涉及6个专利+3个商标+129个卖家的集体诉讼，不是问一句供应商就能避开的。以下SOP是从我自己刚刚执行完两次实际排查（锥形瓶套装 + Owala咖啡杯）后总结出的完整路径。
>
> **关联文档**：[[raw/articles/锥形瓶12件套_专利与版权侵权简化分析]] · [[raw/articles/Owala SmoothSip Slider 侵权风险分析]] · [[Amazon选品方法论总览]] · [[市场分析法]]

## 总览：五层排查漏斗

```
第一层：产品特征拆解（明确"我在查什么"）
    ↓
第二层：商标排查（品牌名/产品名/标语）
    ↓
第三层：设计专利排查（外观/造型/视觉特征）
    ↓
第四层：发明专利排查（功能/结构/原理）
    ↓
第五层：供应商与市场验证（工厂端+平台端）
    ↓
最终判断：Go / No-Go / 需修改设计
```

---

## 第一层：产品特征拆解

> **思考路径**：不拆解清楚产品有哪些特征，就没法针对性地查。一个产品同时涉及商标（品牌名）、设计专利（外观）、发明专利（功能结构）、版权（图案/图片）。必须把每个特征分别列出来，才能确定对应的查询方向。

### 1.1 列出产品的所有可识别特征

| 特征类别 | 要列什么 | 例子（Owala咖啡杯） |
|---------|---------|-------------------|
| **品牌/产品名称** | 已知的品牌名、产品线名、标语 | "Owala" "SmoothSip" "Slider" |
| **整体造型** | 产品形状、轮廓、比例 | 圆柱形杯体+圆弧形杯盖+侧边手柄 |
| **独特设计元素** | 视觉上最突出的1-3个特征 | 顶部滑动片、弧形饮口、杯盖与手柄的衔接方式 |
| **功能结构** | 机械结构、工作原理 | 滑盖式开关、磁吸密封、真空保温 |
| **图案/纹样** | 产品上的图形、印刷、标签 | 品牌Logo、刻度线、装饰图案 |

### 1.2 判断产品类型

```
功能性产品（如锥形瓶、螺丝刀）→ 重点查发明专利 + 设计专利
外观驱动型产品（如首饰、装饰品）→ 重点查设计专利 + 版权
品牌驱动型产品（如保温杯、服装）→ 重点查商标
```

### 1.3 输出物

一张特征清单表，后续每一层排查都对照这张表来查。

## 第二层：商标排查

> **思考路径**：商标是最容易查、最容易避开的侵权类型，也是最容易被忽视的。Owala案例中，如果你的Listing标题里出现了"Owala"这个词，不需要抄设计就已经侵权了。而且商标侵权的后果很严重——亚马逊会直接下架Listing，品牌方可以发起TRO冻结资金。

### 2.1 USPTO商标数据库查询

**工具**：https://www.uspto.gov/trademarks/search

**操作步骤**：

| 步骤 | 操作 | 说明 |
|:----:|------|------|
| ① | 进入 USPTO 商标搜索页，选择 "Word and/or Design Mark Search" | |
| ② | 输入**产品核心关键词**（如："straw" "tumbler" "cup" "bottle"） | 查通用词是否被注册为商标 |
| ③ | 输入**任何你可能在Listing中使用的品牌词** | 包括自拟品牌名，确认没被注册 |
| ④ | 检查搜索结果中的 **Live/Dead 状态** | 只有 "Live" 的有效 |
| ⑤ | 检查注册的 **Goods and Services 类别** | 确认是否覆盖你的产品品类 |

**需要特别警惕的信号**：

| 信号 | 说明 |
|:----|------|
| 商标覆盖的品类和你的产品一致 | 🔴 高——比如"Owala"注册在"杯子/保温瓶"类别 |
| 商标是近1-2年内新注册的 | 🟡 中——可能是新品牌在布局 |
| 同一权利人名下有多个关联商标 | 🟡 中——说明对方有系统性的品牌保护 |

### 2.2 品牌方维权记录查询

**工具**：Google / 法律案例库

**搜索方法**：
```
"[品牌名]" patent infringement
"[品牌名]" trademark lawsuit
"[品牌名]" Amazon sellers sued
```

**思考路径**：有些品牌虽然没有大量的专利，但非常喜欢告卖家（比如Trove Brands）。如果一个品牌有起诉卖家的历史记录，即使它的专利覆盖面不那么强，实际被起诉的风险也很高。

### 2.3 商标排查结论判断

```
你使用的名称是否已被注册？
├─ ✅ 否 → 商标风险低
└─ ❌ 是 → 是否属于同一品类？
   ├─ ✅ 是 → 🔴 高风险，不能使用
   └─ ❌ 否 → 🟡 中风险，建议咨询律师
```

## 第三层：设计专利排查

> **思考路径**：设计专利保护的是"产品长什么样"，而不是"产品有什么功能"。锥形瓶的造型因为是1860年的发明所以不受保护，但Owala的滑盖是近几年设计出来的，有有效的设计专利。这层的核心是：**找到与你的产品视觉上相似的设计专利**。

### 3.1 USPTO 设计专利检索

**工具**：https://ppubs.uspto.gov/pubwebapp/

**操作步骤**：

| 步骤 | 操作 | 说明 |
|:----:|------|------|
| ① | 选择 "Design Patent" 数据库 | |
| ② | 关键词搜索：先用**品类词**（如 "straw" "bottle" "lid" "cup"） | 第一轮宽搜 |
| ③ | 关键词搜索：再用**功能描述词**（如 "slider" "flip top" "push button"） | 第二轮精搜 |
| ④ | 按申请日排序，重点看最近5-10年的专利 | 过期专利无需关注 |
| ⑤ | 逐一看结果中的专利附图和标题 | 找到视觉上相似的设计 |
| ⑥ | 检查专利的 **"LOC Classification"**（洛迦诺分类） | 确认是否属于你的产品品类 |

**设计专利的关键信息**：

```
专利号格式：D开头，如 D696,551、D842,030
保护范围：附图中的实线部分（虚线部分不受保护）
有效期：授权日起15年
权利人：Assignee（专利的当前所有人）
```

### 3.2 Google Patents 补充搜索

**工具**：https://patents.google.com

**搜索方法**：
```
"product name" design
"product feature" patent
assignee:"company name"
```

Google Patents 的优势：搜索结果更智能，可以按相关性排序，而且能同时搜到 US 和 international 专利。

### 3.3 判断设计专利是否可能侵权

这是最复杂也最需要判断力的环节。核心原则：

```
自己产品的视觉特征 vs 专利附图中的实线部分
├─ 整体视觉效果显著不同 → 🟢 低风险
├─ 整体视觉效果相似但在关键特征上有明显差异 → 🟡 中风险，建议修改
└─ 整体视觉效果高度相似 → 🔴 高风险
```

**思考路径**：设计专利侵权的法律判定标准是"普通观察者测试"（Ordinary Observer Test）——一个普通的消费者是否会被误导认为两个产品是同一个来源。这不像发明专利那样必须逐条比对权利要求，而是看整体视觉效果。所以即使你在某个细节上做了修改，如果整体看起来还是像，仍然可能构成侵权。

### 3.4 特别关注"新授权"的设计专利

**思考路径**：Owala 案例中 USD1053662 是 2024年12月才授权的，市面上很多仿品根本没注意到它，但它的保护期还有15年。新授权的专利往往在搜索引擎里排名靠后（因为链接权重低），容易被忽视。建议在搜索时把排序切换到"申请日倒序"。

## 第四层：发明专利排查

> **思考路径**：发明专利保护的是"产品的工作原理/结构/方法"。锥形瓶不需要查发明专利（原理已过期），但Owala的滑盖磁吸密封就有发明专利保护。这一层比设计专利更难排查，因为你需要读懂专利的权利要求（Claims），而不是只看图。

### 4.1 关键功能特征拆解

先列出产品中**可能具有新颖性**的功能特征：

| 特征类型 | 例子 |
|---------|------|
| 机械结构 | 滑盖机构、翻盖卡扣、旋转锁紧 |
| 材质组合 | 双层真空、陶瓷内胆 |
| 使用方法 | 一键开启、磁吸闭合 |
| 制造工艺 | 特殊焊接、涂层工艺 |

### 4.2 专利检索方法

**工具**：Google Patents（优先）+ USPTO

**搜索词组合**：
```
(product feature) AND (bottle OR cup OR container) AND lid
(straw) AND (cartoon OR character OR shape) AND (top OR topper)
```

**关键词设计技巧**：
- 先用宽泛的功能词找到相关领域
- 再用精确的描述词缩小范围
- 搜索 "assignee:公司名" 可以找到该公司的所有专利

### 4.3 如何快速判断一个发明专利是否相关

发明专利不像设计专利那样看图就行，必须读Claims。但Claims又比较难读。以下是一个快速筛选方法：

| 筛选标准 | 操作 | 判定 |
|---------|------|:----:|
| **独立权利要求中的必要技术特征** | 对比你的产品是否包含所有这些特征 | 如果全部包含 → 🔴 高 |
| **优先权日** | 看专利的申请日期 | 早于20年前的专利已过期 🟢 |
| **专利当前状态** | 检查是否已过期或被无效 | "Expired" 或 "Lapsed" 🟢 |

**思考路径**：发明专利侵权判定比设计专利更严格——必须你的产品落入了专利权利要求的保护范围才构成侵权。如果你的产品缺少独立权利要求中的任何一个必要技术特征，就不侵权。但这需要有基本的专利阅读能力，如果判断不了，建议咨询专利律师。

## 第五层：供应商与市场验证

> **思考路径**：这是现有方法论（[[市场分析法]]）中唯一覆盖到的环节——"要求专利号并自行验证"。但它应该发生在前面四层之后，而不是代替前面四层。

### 5.1 供应商端核查（按市场分析法SOP升级版）

向供应商提出以下问题，并**记录书面回复**：

| 问题 | 目的 | 如果对方说"有" |
|------|------|----------------|
| ① "这个产品有没有申请或注册任何专利？" | 确认供应商是否持有专利 | 要求提供专利号，自行验证 |
| ② "有没有签过独家销售协议？" | 确认是否可以卖美国市场 | 要求提供协议内容 |
| ③ "出口美国被海关扣过吗？" | 排查过往纠纷 | 详细问原因 |
| ④ "这个产品是自主设计的还是公模？" | 判断是否是通用设计 | 公模风险更低但也要查 |
| ⑤ "这个产品有授权使用任何品牌/卡通形象吗？" | 排除IP授权问题 | 要求提供授权书 |

**供应商话术示例**：

```
"我们做这个产品需要确认没有在美国的专利风险，你能确认这个产品没有
申请过任何中国或美国的专利吗？如果有，请提供专利号。另外这个产品
是不是公模，有没有其他美国客户在卖同样的款式？"
```

### 5.2 亚马逊平台验证

| 操作 | 查什么 | 怎么查 |
|------|--------|--------|
| 看竞品Listing | 是否标注 "Patent Protected" "Patent Pending" | 在标题/描述/A+内容中搜索 |
| 看竞品品牌名 | 是否存在有品牌备案的竞品 | 点进品牌店铺，看品牌大小 |
| 看差评 | 是否有买家提到"山寨""仿冒" | Review 搜索 "copy""fake""patent" |

### 5.3 涉诉记录查询

**工具**：Google Scholar / Justia / CourtListener

**搜索**：
```
"brand name" infringement
"company name" lawsuit patent
"product type" patent case
```

**重点关注的信号**：

| 信号 | 风险级别 |
|:----|:--------:|
| 品牌方在过去3年内起诉过卖家 | 🔴 高——说明对方在主动维权 |
| 品牌方有专门的IP律所合作 | 🔴 高——说明维权是系统性的 |
| 同一品牌涉及多方诉讼 | 🟡 中——可能是NPE（专利流氓） |
| 没有找到任何涉诉记录 | 🟢 低——但仍然不能100%排除 |

## 第六层：综合判断

### 6.1 决策矩阵

把所有排查结果汇总到一张表中：

| 维度 | 结果 | 风险 |
|:----|:----|:----:|
| 商标 | 是否有冲突商标 | 🟢🟡🔴 |
| 设计专利 | 是否有相似外观专利 | 🟢🟡🔴 |
| 发明专利 | 是否落入权利要求范围 | 🟢🟡🔴 |
| 供应商 | 是否有专利声明/独家协议 | 🟢🟡🔴 |
| 维权记录 | 品牌方是否有起诉历史 | 🟢🟡🔴 |

### 6.2 最终判断规则

```
如果【任何一项】为🔴：
→ ❌ No-Go。必须修改设计或更换产品。

如果【两项及以上】为🟡：
→ ⚠️ 谨慎。建议咨询专利律师后再决定。

如果【所有项】为🟢 或 只有一项🟡：
→ ✅ Go。记录排查依据后推进。
```

### 6.3 文档化要求

每个完成排查的产品，必须输出一份侵权分析文档并保存在 `raw/` 目录，包含：

1. 产品特征拆解表
2. 搜索关键词和使用的工具列表
3. 找到的所有相关专利号和商标号
4. 每个风险的判断理由
5. 最终结论（Go / No-Go）

**格式参考**：[[raw/articles/Owala SmoothSip Slider 侵权风险分析]]

### 风险提示的优先级排序

```
🔴 商标侵权（后果最直接：Listing下架+资金冻结）
🔴 设计专利侵权（后果严重：产品下架+赔偿）
🟡 发明专利侵权（需要比对权利要求，专业门槛最高）
🟡 版权侵权（图片/文案/图案）
🟢 商业外观侵权（Trade Dress，适用面较窄）
```
